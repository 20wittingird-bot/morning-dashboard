# 朝のダッシュボード

天気・今日の服装提案(相性チェック付き)・今日の予定(深夜アニメの放送スケジュール+その日のメモ)・
ニュースを1画面にまとめた、GitHub Pages + GitHub Actionsで動く静的サイトです。
毎朝自動で内容が更新されます。

## できること

- 天気(都市名を指定するだけ、APIキー不要)
- 天気と持ち服リストから、AIが今日のコーデを提案
- 持ち服リストから1つ選ぶと、相性の良い他のアイテムを表示
- 深夜アニメの放送スケジュールを登録すると、毎週その曜日に自動で「今日の予定」に表示
  (「26:00」のような深夜表記=翌日午前2:00にも対応)
- その日限りのメモを自由入力
- 主要ニュース + 自分で登録したキーワードのニュース
- 持ち服・アニメスケジュール・メモの登録は、サイト上の「+」ボタン→その場で開くテキストボックスから
  GitHubのIssueとして送信する形式(ブラウザにAPIキー等を一切持たせない安全な方式)

## セットアップ手順

### 1. GitHubリポジトリを作成する

1. GitHubで新しいリポジトリを作成します(例: `morning-dashboard`)。
2. このフォルダの中身をすべてそのリポジトリにアップロードします。

### 2. GitHub Pagesを有効にする

1. **Settings → Pages** を開く
2. **Source** を `Deploy from a branch` に設定
3. Branch を `main`、フォルダを `/ (root)` に設定して保存
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でサイトが公開されます

### 3. Actionsの権限を設定する

1. **Settings → Actions → General** を開く
2. 「Workflow permissions」で **Read and write permissions** を選択して保存

### 4. Anthropic APIキーを登録する

1. **Settings → Secrets and variables → Actions** を開く
2. **New repository secret** で Name に `ANTHROPIC_API_KEY`、Value にご自身のAPIキーを入力して保存

### 5. Issue用のラベルを作成する

「+」ボタンからの登録は、あらかじめ用意した4種類のラベル付きIssueとして送信されます。
**Issues → Labels → New label** から、以下の4つを作成してください(色は任意)。

| ラベル名 | 用途 |
|---|---|
| `wardrobe-add` | 持ち服の一括追加 |
| `wardrobe-remove` | 持ち服の削除 |
| `schedule-memo` | 今日限りのメモ登録 |
| `schedule-anime` | アニメ放送スケジュールの一括登録 |

> ラベルが存在しないと、Issue作成時にラベルが付かず自動処理が動きません。

### 6. config.json を編集する

```json
{
  "city": "東京",
  "news_keywords": ["生成AI", "為替"]
}
```

- `city`: お住まいの都市名(日本語でOK)
- `news_keywords`: 追いたいニュースのキーワードを好きなだけ登録

### 7. 初期データの登録

以下はサイト上の「+」ボタンからでも登録できますが、最初にまとめて入れておきたい場合は
`data/` 内のファイルを直接編集しても構いません。

- `data/wardrobe.json`: 持ち服(カテゴリ+アイテム名)
- `data/anime_schedule.json`: アニメの毎週スケジュール(作品名・曜日・時刻)

### 8. 初回の動作確認

1. **Actions** タブを開き、「朝の情報を自動更新」を **Run workflow** で手動実行
2. 数十秒〜1分ほどで `data/*.json` が更新されます
3. サイトを開いて表示を確認してください

### 9. ホーム画面に追加する

スマホのブラウザでサイトを開き、共有メニューから「ホーム画面に追加」を選ぶと、
アイコンをタップするだけで開けるようになります。

## 「+」ボタンからの登録方法

サイト上の「今日の予定」「持ち服リスト」の横にある「+」ボタンを押すと、
その場でテキストボックスが開きます。入力して送信ボタンを押すと、
GitHubのIssue作成画面が新しいタブで開きます。**内容を確認してから
GitHub側で「Submit new issue」を押すと登録が完了します**(自動送信はしません)。

### 今日のメモ

自由記述。送信するとその日限りの予定として登録されます。

### アニメ一括登録

```
アニメA 月曜 23:00
アニメB 火曜 26:00
```
のように、1行1作品で複数まとめて登録できます。一度登録すれば、毎週その曜日に
自動で「今日の予定」に表示されます(再登録は不要です)。

### 持ち服の一括登録

```
アウター
ダウンジャケット
デニムジャケット

トップス
白シャツ
```
のように、カテゴリ見出しの下にアイテム名を改行で並べてください。

### 持ち服の削除

「+」ボタンからではなく、GitHubのIssueを直接作成し、ラベル `wardrobe-remove` を付けて
本文に削除したいアイテム名を1行ずつ書いてください。

## ファイル構成

```
index.html / style.css / app.js   … 表示側(静的サイト)
config.json                        … あなたが編集する設定
data/*.json                        … Actionsが自動更新するデータ
scripts/*.py                       … データ取得・生成スクリプト
.github/workflows/*.yml            … 自動実行の定義
```

## 既知の制約

- 完全に「開かずに見える」ホーム画面ウィジェットではなく、開くと即座に最新情報が見られるWebアプリです。
- 「+」ボタンからの登録は、GitHub上でのワンタップ確認(Submit new issue)が必要です
  (ブラウザにAPIキー等を持たせないための安全設計です)。
- 相性チェックの結果は、直近の自動更新時点でのAI生成結果です(リアルタイム生成ではありません)。
- カレンダー機能は含まれていません(GitHub無料プランでは公開リポジトリが前提のため、
  個人情報公開のリスクを避けて見送っています)。
